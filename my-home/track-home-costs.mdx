In **My Home**, open **Money** and select **Log a cost**. Only owners and co-owners see **Money**.

1. Open **My Home**, then **Money**.
2. Select **Log a cost**.
3. Add **What was done**, **When**, **Who did it** and **What it cost**.
4. Add the **Receipt**, if you have it.
5. Select **Log it**.

A cost you log here also shows on **Activity**, and the other way round.

## Costs that repeat

For a cost that comes back, like insurance or property tax, select **Add a regular cost**. Add **What**, the **Amount** and **How often**, then select **Add**.
